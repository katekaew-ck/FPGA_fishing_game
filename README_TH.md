# เกมตกปลา FPGA — ชุดไฟนอลบอร์ด Game

Top entity บอร์ด Game: `game_top`. ใช้ VHDL 9 ไฟล์ที่อยู่ในโฟลเดอร์หลักนี้เท่านั้น ไม่ใส่ไฟล์ UART test หรือไฟล์ซ้ำชื่อ entity ในโปรเจกต์เดียวกัน

โฟลเดอร์ `board1_controller/` มีซอร์สโค้ดบอร์ด 1 เดิมครบ 8 ไฟล์และตารางขาพินของตัวเอง หากบอร์ด 1 ส่ง UART ได้อยู่แล้วไม่จำเป็นต้องแฟลชใหม่ ถ้าจะ Build บอร์ด 1 ให้ตั้ง top = `controller_top` และใช้เฉพาะ 8 ไฟล์ในโฟลเดอร์นั้น ไม่รวมกับไฟล์ของบอร์ด Game

## กติกา

- บอร์ด 1 ส่งตำแหน่ง Rotary และสถานะปุ่มผ่าน UART ตามโปรโตคอลเดิม `A5 5A POS_LO POS_HI BUTTONS XOR` ที่ 115200 baud
- READY กดปุ่มซ้ายหรือขวาเพื่อเริ่ม; เล่น 60 วินาที
- ปุ่มซ้าย/ขวาขยับเบ็ดแนวนอน; หมุน Rotary ควบคุมขึ้นลง
- ทิศการหมุนใช้แบบที่แก้ล่าสุดใน `game_datapath.vhd` (`hook_y_reg - reel_delta * 3`)
- ปลา 5 ตัวว่ายพร้อมกันในระดับความลึกต่างกัน; เมื่อจับได้ ปลาตัวนั้นหายจากทะเลและติดเบ็ด ต้องดึงขึ้นถึงผิวน้ำจึงได้คะแนนและมีปลาใหม่เกิดในระดับความลึกใกล้เดิม ปลาอีกสี่ตัวว่ายต่อ
- ปลาปกติสีเหลืองว่ายช้า +1, สีฟ้าว่ายปานกลาง +5, สีชมพูว่ายเร็ว +10; ปลาแรร์สีรุ้ง +20 ว่าย 3 พิกเซลต่อเฟรม
- ทุกครั้งที่เริ่มเกม จะมีปลาครบทั้งสี่ชนิดอย่างน้อยชนิดละหนึ่งตัวทันที; ปลาตัวที่ห้าสุ่มชนิด
- เมื่อจับปลาแล้วเกิดใหม่ จะสุ่มปลาแรร์ประมาณ 3%; ในปลาที่ไม่แรร์ สุ่มสีเหลือง/ฟ้า/ชมพู 35%/40%/25%
- เกณฑ์สุ่มเกิดใหม่จาก 1–65535: 1–1966 แรร์, 1967–24215 เหลือง, 24216–49643 ฟ้า, 49644–65535 ชมพู
- เบ็ดแตะรองเท้าบูตจะเสีย 5 คะแนนทันที (ไม่ติดลบ) และรองเท้าย้ายตำแหน่ง
- เบ็ดแตะปลาไหลไฟฟ้าจะขยับไม่ได้ 5 วินาที ปลาอื่นยังว่าย และเวลาของเกมยังเดินต่อ; ปลาไหลย้ายตำแหน่ง
- GAME OVER แสดงคะแนนรวม: กดซ้ายเพื่อเริ่มเกมใหม่ กดขวาเพื่อกลับ READY
- คะแนนแสดงได้ 000–999 และหยุดที่ 999; ไม่มีเสียง buzzer

## สิ่งที่เปลี่ยนจากเกมก่อนหน้า

- `game_datapath.vhd`: ปลาห้าช่อง ตำแหน่ง Y ต่างกัน, LFSR สำหรับสุ่มชนิดปลา, รองเท้า, ปลาไหล, stun และคะแนน
- เก็บช่องปลาที่ติดเบ็ดแบบ one-hot 5 บิต และเลือกปลาตามระดับความลึกก่อนวาด sprite เพื่อลดวงจรที่ Placer ต้องวาง
- `game_top.vhd`: ต่อสัญญาณตำแหน่ง/ชนิดของปลาทั้งห้าไปยัง renderer; พอร์ตภายนอกเหมือนเดิม
- `render.vhd`: ปลาแต่ละสี หางและตา; ปลาแรร์ลายรุ้ง; เรือและคนตกปลา; ปะการัง สาหร่าย ปลาดาว พื้นทะเล; รองเท้าและปลาไหล; ข้อความ READY/PRESS TO START/GAME OVER
- `input_manager.vhd`: ข้ามการกระโดดของตำแหน่ง Rotary มากกว่า 20 ขั้น/เฟรม หากบอร์ดส่งรีเซ็ตค่าเป็น 5000 ระหว่างเกม
- `uart_rx.vhd`, `packet_parser.vhd`, `vga_timing.vhd`, `game_controller.vhd`, `game_timer.vhd`: เหมือนชุดก่อน

## บอร์ด 2: ขาพิน

ทั้งหมดใช้ IOSTANDARD LVCMOS33; clock H11 period 20 ns:

| Port | Pin | Extra |
|---|---|---|
| clk | H11 | Clock 20 ns |
| reset_button | J14 | PULLDOWN true |
| uart_rx | G11 (J5 ขา 10) | PULLUP true |
| vga_r[0..3] | B6, D3, C3, A4 | |
| vga_g[0..3] | A3, B3, A2, B5 | |
| vga_b[0..3] | A5, B2, B1, C5 | |
| vga_hsync | C4 | |
| vga_vsync | E4 | |

ใช้ไฟล์ `game_board2.xdc` เป็นข้อมูลอ้างอิงถ้ากรอกขาในโปรแกรมรายวิชาเอง ต่อ UART TX ของบอร์ด 1 (G11) ไปยัง RX ของบอร์ด 2 (G11) และต่อ GND ร่วมกัน

## เช็กก่อนแฟลช

1. Build ฝั่ง Game ทั้ง 9 ไฟล์ โดยตั้ง top = `game_top`; ตรวจ ERROR แรกจาก Log หาก Build ล้มเหลว
2. หน้า READY ต้องขึ้น `PRESS TO START`; กดปุ่มแล้วภาพเกมและตัวจับเวลาเริ่ม
3. ปลาห้าตัวต้องอยู่คนละระดับ Y และเคลื่อนที่เอง; เมื่อจับหนึ่งตัว อีกสี่ตัวไม่หาย
4. ดึงปลาที่ติดเบ็ดขึ้นถึง Y=80 จึงได้คะแนน; รองเท้า -5 เมื่อแตะ, ปลาไหลแสดง `STUN` และหยุดเบ็ด 5 วินาที
5. เวลา 0 เข้า GAME OVER; ตรวจปุ่มซ้ายเริ่มใหม่และปุ่มขวากลับ READY

หมายเหตุ: สภาพแวดล้อมที่สร้างชุดนี้ไม่มี Vivado/GHDL จึงยังไม่สามารถยืนยันการสังเคราะห์และการทำงานจริงบน FPGA ได้; ต้อง Build และทดสอบด้วยโปรแกรมของรายวิชาก่อนแฟลช
